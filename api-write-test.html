The test gives Team E a temporary unique name, verifies it through the public API, and restores all five team settings. The original names and colours are checked again at the end.

Nothing is written until you press the test button.
Run this when nobody else is editing team settings. It will update the Team Settings timestamp. The token is sent only to your Apps Script endpoint by this page, held temporarily in memory, and cleared when the test finishes. It is not saved to local storage.
The API rejects unknown operations and writes only the dedicated Team Settings tab.
