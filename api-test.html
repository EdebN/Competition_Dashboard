What this page tests

Read requests use the test endpoint's JSONP response so the browser can read the result across origins. The write test sends only the fixed {"action":"testWrite","value":"WRITE_TEST"} marker. It cannot edit game scores or fixtures.

This is a temporary diagnostic page, not the production API or a security test. The endpoint should remain limited to test writes until we design and enforce the real permissions.

Expected successful read: service = competition-community-api, mode = test. After writing, value should be WRITE_TEST.
